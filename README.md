# Product Review Sentiment Analysis

## Overview

This project performs sentiment analysis on product reviews collected from e-commerce platforms. It predicts whether a review expresses a Positive, Negative, or Neutral sentiment using Natural Language Processing (NLP) and Machine Learning.

## Features

- Data preprocessing
- Text cleaning
- Tokenization
- Sentiment prediction
- Data visualization
- Machine Learning models
- Accuracy evaluation

## Technologies Used

- Python
- Pandas
- NumPy
- NLTK
- TextBlob
- VADER
- Scikit-learn
- Matplotlib

## Project Workflow

Dataset
→ Data Cleaning
→ Feature Extraction
→ Sentiment Analysis
→ Result Visualization

## Installation

```bash
pip install -r requirements.txt
python source240.py
```

## Results

The project classifies customer reviews into Positive, Negative, and Neutral sentiments with high accuracy using lexicon-based sentiment analysis.
